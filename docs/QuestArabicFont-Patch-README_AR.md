# إصلاح مربعات نصوص المهام في The Ranchers

## سبب المشكلة

نصوص المهام العربية موجودة في ملفات اللعبة، لكن بعض عناصر TextMeshPro في مشهد `level6` كانت تعيّن خطوطًا لاتينية أو صينية صراحةً. هذا يتجاوز خط الاحتياط العربي العام؛ لذلك بقيت أوصاف المهام المكتملة وغيرها على هيئة مربعات.

## ما الذي يغيّره الإصلاح؟

يحدّث ستة مراجع خطوط في عناصر وصف المهمة وعنوانها ووصف المهام المكتملة إلى `NotoSansArabic-Medium SDF` (معرّف الخط 1553 في `sharedassets0.assets`). لا يغيّر النصوص أو التخزين أو ملفات الخط نفسها.

## التثبيت

1. أغلق The Ranchers بالكامل.
2. شغّل `Run-QuestArabicFont-Patch.cmd` بالنقر المزدوج. يستخدم المسار الافتراضي:
   `D:\SteamLibrary\steamapps\common\TheRanchers\TheRanchers_Data`
3. إذا كانت اللعبة مثبتة في مكان آخر، شغّل ملف PowerShell مباشرةً مع تمرير مسار مجلد `TheRanchers_Data`:
   `powershell -ExecutionPolicy Bypass -File .\Install-QuestArabicFont-Patch.ps1 -GameDataPath 'E:\مسار اللعبة\TheRanchers_Data'`
4. ينشئ المثبّت نسخة `level6.backup-before-quest-font-<وقت>.bak` قبل التعديل، ويتوقف إذا لم تتطابق نسخة اللعبة أو مراجع الخطوط المتوقعة.

## ملاحظة الإصدار

الإصلاح مبني على The Ranchers `v0.8.10.872` وUnity `2022.3.62f3`. لا تستخدمه بعد تحديث اللعبة قبل إعادة فحص المشهد. مشكلة اتجاه النص المكتوب داخل الهاتف منفصلة، ولم يغيّر هذا الإصلاح معالجة إدخال الهاتف.
